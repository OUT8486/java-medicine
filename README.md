# 药店管理系统 - 技术架构文档

## 项目概述
这是一份关于药店管理系统的Spring Boot项目架构分析文档。

## 系统架构
本系统采用经典的分层架构设计：
- **表现层**：处理用户请求和响应
- **业务逻辑层**：实现核心业务功能
- **数据访问层**：处理数据持久化
- **实体层**：定义数据模型
- **配置层**：管理应用配置

## 技术栈
- Spring Boot
- Spring MVC
- Spring Data JPA / MyBatis
- MySQL
- HTML / Thymeleaf

## 设计原则
- 模块化设计
- 关注点分离
- RESTful API
- 统一异常处理
